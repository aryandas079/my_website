## System Architecture

Building modern AI-assisted applications requires tight coordination between responsive frontend state, resilient API middleware, and relational persistence. This full-stack system pairs a **React** and **Next.js** interface styled with **Tailwind CSS** alongside a dedicated **Node.js / Express.js** backend and **PostgreSQL** database.

## End-to-End Request Lifecycle

| Layer | Technology | Responsibility | Measured Latency |
| :--- | :--- | :--- | :--- |
| Presentation & State | `React` · `Next.js` · `TypeScript` | Optimistic UI updates & streaming | `< 16 ms` frame budget |
| API Gateway | `Node.js` · `Express.js` | Rate limiting, validation & auth | `18 ms` mean |
| Persistence | `PostgreSQL` | Normalized schemas & JSONB logs | `11 ms` query time |

## UI/UX & Creative Design Focus
