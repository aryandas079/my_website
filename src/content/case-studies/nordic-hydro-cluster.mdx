## Problem Statement & Electrical Context

Distribution feeders experience sharp nonlinear demand spikes driven by ambient temperature shifts and industrial switching loads. As part of my Electrical Engineering & Machine Learning exploration at **NIT Silchar**, this project models 15-minute interval active power (`kW`) and reactive power (`kVAr`) telemetry to forecast 24-hour peak load windows.

Using `SciPy` Fast Fourier Transform (FFT) spectral decomposition alongside `Pandas` rolling window statistics, noisy meter transients are filtered before training a `Scikit-Learn` ensemble regressor.

## Feature Engineering Pipeline

| Stage | Library Stack | Dimensionality | Computation Time |
| :--- | :--- | :--- | :--- |
| Harmonic Filtering | `NumPy` · `SciPy` | 32 spectral bins | 3.8 ms |
| Lag & Rolling Matrix | `Pandas` | 48 temporal features | 5.1 ms |
| Ensemble Regression | `Scikit-Learn` | 500 estimators | 5.2 ms |

## Key Engineering Takeaways

Visualizing residual distributions in `Matplotlib` and `Seaborn` revealed that reactive power factor drift precedes afternoon transformer thermal peaks by 45 minutes, enabling proactive tap-changer scheduling.
